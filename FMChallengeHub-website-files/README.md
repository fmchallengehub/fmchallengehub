# FMChallengeHub

A static starter website for FMChallengeHub, built with HTML, CSS and vanilla JavaScript.

## Preview locally
Open `index.html` in a browser.

## Deploy to Cloudflare Pages
- Connect this GitHub repository to a **Cloudflare Pages** project.
- Framework preset: **None**
- Build command: leave blank
- Build output directory: `/` (or `.` if Cloudflare requires a relative directory)
- Root directory: `/`

This is the first frontend version. User accounts, saved progress, leaderboards and journals will need a backend such as Supabase in a later phase.

Fan-made community project; not affiliated with Sports Interactive or SEGA.
